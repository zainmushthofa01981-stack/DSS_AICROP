DSS AICROP PWA

Cara install:
1. Upload seluruh folder ini ke hosting HTTPS (GitHub Pages, Netlify, Vercel, Firebase Hosting, dll.).
2. Android/Chrome: buka URL -> menu -> Install app / Add to Home screen.
3. iPhone/iPad/Safari: buka URL -> Share -> Add to Home Screen.

Catatan:
- PWA membutuhkan HTTPS agar service worker/install berfungsi normal.
- File ini dapat dibungkus lebih lanjut dengan Capacitor untuk APK/AAB Android dan proyek iOS.
